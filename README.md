# Salary App

アルバイトの勤務時間や勤務コマ数を記録し、日ごとの給与や月ごとの給与見込みを計算・管理するWebアプリです。

複数の勤務先を管理し、時給制・コマ制の給与計算に対応することを目指しています。

## 開発環境

- Java 21
- Spring Boot 4.0.8
- Maven
- Thymeleaf
- Spring Data JPA
- H2 Database
- JUnit
- Git / GitHub

## 要件定義

### 1. アプリの目的

アルバイトの勤務記録を登録し、勤務時間や勤務コマ数から給与を計算する。

また、月ごとの勤務時間・給与見込み・実際に受け取った給与を確認できるようにする。

### 2. 利用者

- 1人で利用する
- ログイン機能は初期バージョンでは実装しない

### 3. 勤務先管理

複数の勤務先を登録できる。

勤務先には以下を登録する。

- 勤務先名
- 給与方式
- 通常時給
- 割増時給
- 1コマあたりの給与

給与方式は、時給制とコマ制を想定する。

勤務先の登録・編集・削除を行えるようにする。

### 4. 勤務記録

勤務記録には、給与方式に応じて以下を登録する。

共通項目：

- 勤務日
- 勤務先

時給制の項目：

- 開始時刻
- 終了時刻
- 休憩時間

コマ制の項目：

- 勤務コマ数

時給制では、1日に複数の勤務記録を登録できる。

時刻は10分単位で入力できるようにする。

日付をまたぐ勤務は初期バージョンでは対象外とする。

### 5. 給与計算

#### 時給制

基本的な計算方法は以下とする。

`適用時給 × 実働時間`

実働時間は以下で計算する。

`終了時刻 − 開始時刻 − 休憩時間`

以下の場合は割増時給を適用する。

- 平日の17:00以降
- 土曜日
- 日曜日
- 日本の祝日

平日の17:00をまたぐ勤務は、通常時給と割増時給に分けて計算する。

複数の割増条件が重なっても、割増は重複させない。

1円未満の金額は切り捨てる。

#### コマ制

基本的な計算方法は以下とする。

`1コマあたりの給与 × 勤務コマ数`

コマ制では、勤務先に設定された1コマあたりの給与と、勤務記録に登録されたコマ数から給与を計算する。

時給制とコマ制で、不要な入力項目を区別できるようにする。

### 6. 給与情報の履歴

勤務記録には、その勤務を登録した時点の給与計算に必要な情報を保存する。

時給制では通常時給・割増時給、コマ制では1コマあたりの給与などを保存することを想定する。

そのため、後から勤務先の給与設定を変更しても、過去の勤務記録の給与計算に影響しないようにする。

### 7. 月別給与

月ごとに以下を確認できるようにする。

- 勤務先ごとの勤務時間
- 勤務先ごとの給与見込み
- 勤務先ごとの実際の給与
- 月全体の勤務時間・給与見込み・実際の給与

前月・当月・翌月を切り替えられるようにする。

実際の給与は、給与を受け取った後に手動で入力・保存する。

### 8. 画面構成

- ホーム画面
- 勤務先登録・編集画面
- 勤務記録カレンダー・一覧画面
- 勤務記録登録・編集画面
- 給与計算画面

ホーム画面から勤務先管理・シフト管理・給与計算の各機能へ移動できるようにする。

勤務先管理画面では、勤務先の一覧表示・追加・編集・削除を行えるようにする。

### 9. データベース

#### Workplace（勤務先）

- id
- name
- pay_type
- regular_wage
- premium_wage
- lesson_wage

給与方式やコマ給の項目は、実際のエンティティの実装に合わせて管理する。

#### Shift（勤務記録）

- id
- workplace_id
- work_date
- start_time
- end_time
- break_minutes
- pay_type
- lesson_count
- regular_wage
- premium_wage

コマ制に必要な項目や、勤務登録時点の給与情報を保持するための項目を設ける。

#### Salary（実際の給与）

- id
- workplace_id
- year
- month
- actual_amount

勤務先・対象年月ごとの実際の給与を保存する。

勤務時間や給与見込みは、勤務記録から計算する方針とする。

日本の祝日は、外部APIまたは祝日データを利用して判定する予定。

※データベースの項目は設計上の一覧であり、実際のエンティティやテーブル構造に合わせて更新する。

### 10. 初期バージョンでは実装しないもの

- ログイン・ユーザー登録
- 複数ユーザー対応
- 交通費

- 深夜割増
- 日付をまたぐ勤務
- 銀行口座との連携
- 給与の自動取得
- 管理者画面
- チャット機能

## 起動方法

### 必要な環境

- Java 21
- Git

### アプリケーションの起動

リポジトリを取得した後、プロジェクトのルートディレクトリで以下を実行する。

```bash
./mvnw spring-boot:run
```

起動後、ブラウザで以下にアクセスする。

http://localhost:8080

アプリケーションを停止する場合は、ターミナルで `Ctrl + C` を押す。

## テスト方法

プロジェクトのルートディレクトリで以下を実行する。

```bash
./mvnw test
```

テスト結果を確認し、給与計算や入力チェックなどの動作を検証する。
