# Salary App

アルバイトの勤務時間を記録し、日ごとの給与や月ごとの給与見込みを計算・管理するWebアプリです。

## 開発環境

* Java 21
* Spring Boot 4.0.8
* Maven
* Thymeleaf
* Spring Data JPA
* H2 Database
* Git / GitHub

## 要件定義

### 1. アプリの目的

アルバイトの勤務記録を登録し、勤務時間から日ごとの給与を計算する。

また、月ごとの勤務時間・給与見込み・実際に受け取った給与を確認できるようにする。

### 2. 利用者

* 1人で利用する
* ログイン機能は初期バージョンでは実装しない

### 3. 勤務先管理

複数の勤務先を登録できる。

勤務先には以下を登録する。

* 勤務先名
* 通常時給
* 割増時給

勤務先の登録・編集・削除を行える。

### 4. 勤務記録

勤務記録には以下を登録する。

* 勤務日
* 勤務先
* 開始時刻
* 終了時刻
* 休憩時間

1日に複数の勤務記録を登録できる。

時刻は10分単位で入力できるようにする。

日付をまたぐ勤務は初期バージョンでは対象外とする。

### 5. 時給計算

基本的な計算方法は、

`適用時給 × 実働時間`

とする。

実働時間は、

`終了時刻 − 開始時刻 − 休憩時間`

で計算する。

以下の場合は割増時給を適用する。

* 平日の17:00以降
* 土曜日
* 日曜日
* 日本の祝日

平日の17:00をまたぐ勤務は、通常時給と割増時給に分けて計算する。

複数の割増条件が重なっても、割増は重複させない。

1円未満の金額は切り捨てる。

### 6. 時給の履歴

勤務記録には、その勤務を登録した時点の通常時給・割増時給を保存する。

そのため、後から勤務先の時給を変更しても、過去の勤務記録の給与計算には影響しない。

### 7. 月別給与

月ごとに以下を確認できるようにする。

* 勤務先ごとの勤務時間
* 勤務先ごとの給与見込み
* 勤務先ごとの実際の給与
* 月全体の合計

前月・当月・翌月を切り替えられるようにする。

実際の給与は、給与を受け取った後に手動で入力する。

### 8. 画面構成

* ホーム画面
* 勤務先登録・編集画面
* 勤務記録カレンダー・一覧画面
* 勤務記録登録・編集画面
* 給与計算画面

ホーム画面には勤務先をカード形式で表示し、勤務先の追加・編集・削除を行えるようにする。

### 9. データベース

#### Workplace

* id
* name
* regular_wage
* premium_wage

#### Shift

* id
* workplace_id
* work_date
* start_time
* end_time
* break_minutes
* regular_wage
* premium_wage

#### Salary

* id
* workplace_id
* year
* month
* actual_amount

勤務時間や計算後の給与はデータベースに保存せず、勤務記録から計算する。

日本の祝日は外部のAPI・データを利用して判定する予定。

### 10. 初期バージョンでは実装しないもの

* ログイン・ユーザー登録
* 複数ユーザー対応
* 交通費
* 税金・社会保険料
* 深夜割増
* 日付をまたぐ勤務
* 銀行口座との連携
* 給与の自動取得
* 管理者画面
* チャット機能
